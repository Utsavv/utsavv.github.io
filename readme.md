# Personal website of Utsav Verma

This is a Jekyll site (al-folio theme). To run it locally:


cd /Users/utsavverma/git/utsavverma.github.io
bundle install
bundle exec jekyll serve
Then open http://localhost:4000 in your browser.

If bundle install complains about missing Ruby, check .ruby-version (it expects a specific Ruby version) — let me know if you hit errors and I'll help debug.
